# v1.0.0

First public release of Skyburst Nocturne.

- Added a continuously animated fireworks display and layered starfield.
- Added adjustable firework rate, size, and speed, star density, color palette, and scene brightness.
- Added per-setting random choices and randomization of all settings at each session start.
- Added the remote-friendly settings activity and validated settings provider.
- Added a standalone ADB installer and checksum verification.

Upgrade path: install over an existing signed release with the included installer. The package ID and release signing certificate remain stable. No breaking configuration changes.

Device evidence: Google TV emulator, Android 14 API 34, 1920 x 1080. The app preview rendered and animated; direct DreamService activation was blocked by the production emulator image. Physical Fire TV, Android TV, and Google TV results are not available; see [device verification](../VERIFICATION.md).
